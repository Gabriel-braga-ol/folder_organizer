# folder_organizer
Projeto para organizar pastas

Criei esse projeto na intensão de organizar a pasta download que estava com quase 1000 arquivos de diferentes formatos e tudo misturado.

Esse script organiza cada arquivo em suas pastas correspondentes. 

Por exemplo: 

Arquivos .jpg, .jpeh, .png, .gif e etc são organizados na pasta imagens

Arquivos .pdf são organizados na pasta PDFs

E por aí vai... Arquivos que não possui uma pasta específica são organizados na pasta 'outros'

Trata-se de um projeto simples, mas que é bastante útil no dia a dia, principalmente se você baixa muita coisa na internet.
